# Security Policy

## Reporting a vulnerability

Report security issues in Akash Console privately through GitHub: https://github.com/akash-network/console/security/advisories/new

Please do not open a public issue, pull request or discussion for a vulnerability.

A useful report includes:

- the affected application or endpoint
- the steps to reproduce it, with requests and responses where possible
- what an attacker gains from it
- how we can reach you for follow-up questions

## Scope

- The hosted Console at https://console.akash.network and its API
- The code on the `main` branch of this repository

## Testing guidelines

- Use only accounts you created yourself, and do not access, change or delete data that belongs to other users.
- Do not run denial-of-service tests or high-volume automated scans against production.
- Do not use social engineering against Akash Network staff or users.
- Stop and report as soon as you can confirm an issue. Do not use it to go further.

The same contact is published at https://console.akash.network/.well-known/security.txt.
